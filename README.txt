PARAS DOORS — PAIRED PREVIEW FILES

1. Keep index.html and admin.html together in the same website folder.
2. Open admin.html in the same browser and website origin as index.html.
3. Add a product, name, category, description, optional price and photo; click Save.
4. Open or refresh index.html in that same browser/origin to see the saved product.

IMPORTANT:
This is browser-local storage, not a shared online product database. If hosted on a static site, products saved by the owner in their browser will not appear to visitors on other devices. For public live updates, integrate a cloud database and secure owner authentication (for example Firebase or Supabase). Do not publish the demo admin as a secure admin portal.
